# 리포트 학기별 순서 관리

리포트 DB의 `학기`(텍스트)와 `학기 내 순서`(숫자)만 수정하면 됩니다. 글을 삭제하거나 게시일을 바꿀 필요가 없습니다. 관리하는 속성 이름은 그대로 유지하세요.

## 글을 올릴 때

1. PDF 업로드와 제목·분류·작성자·게시일·파일 링크 입력을 마칩니다.
2. `학기`에 `2026-2`처럼 연도 네 자리, 하이픈, 학기 1 또는 2를 입력합니다. 게시일에서 학기를 자동 추정하지 않습니다.
3. `학기 내 순서`에 `10, 20, 30…`처럼 양수를 입력합니다. 같은 학기에서 작은 숫자가 먼저 표시됩니다.
4. 검토 후 `공개`를 체크하고 사이트를 확인합니다. 서명된 변경 알림으로 목록 캐시가 갱신되며, 알림이 늦으면 새 요청 기준 최대 약 2분을 기다린 뒤 새로고침합니다. 이미 열린 화면은 자동으로 재정렬되지 않습니다.

예를 들어 순서가 10·20·30인 세 글 중 마지막 글을 두 번째로 옮기려면 30을 15로 바꿉니다. 새 학기는 다시 10부터 시작합니다. 모든 과거 자료의 번호를 다시 매기지 않습니다.

## 노션에서 보는 방법

- `전체 · 학기순`: 학기 내림차순, 학기 내 순서 오름차순으로 전체 자료를 관리합니다. 비공개 작성 예시도 이 보기에는 나타납니다.
- `2026-2 관리`: 학기가 `2026-2`인 자료만 보고 수정합니다. 다음 학기에는 이 보기를 복제하여 이름과 학기 필터를 함께 바꿉니다. 보기 이름만 바꿔서는 필터가 바뀌지 않습니다.
- 새 학기에 등록할 글은 해당 학기의 관리 보기에서 추가하면 편리합니다. 저장 후 학기 값을 확인합니다.

노션 보기의 정렬은 작업을 돕는 표시 설정입니다. 웹사이트는 두 속성의 실제 값을 읽습니다. 노션에서 행을 드래그하거나 다른 보기로 바꾸는 것만으로 웹사이트 순서는 바뀌지 않습니다.

## 비어 있거나 중복된 값

| 입력 상태 | 웹사이트 처리 |
| --- | --- |
| 학기가 올바르고 순번도 있음 | 최신 학기부터, 같은 학기에서는 작은 순번부터 |
| 학기는 있으나 순번이 비어 있음·0·음수 | 해당 학기의 번호 있는 글 뒤에 표시 |
| 학기가 비어 있거나 `2026-3` 등 잘못된 형식 | 전체 목록 뒤에 표시하고 순번은 무시 |
| 같은 학기에 같은 순번 | 게시일 최신순, 제목, ID로 순서 결정 |

노션의 빈값·동일값 표시 순서와 사이트의 보조 정렬은 다를 수 있습니다. 노션과 사이트를 정확히 맞추려면 공개할 글에 올바른 학기와 서로 다른 순번을 입력하세요.

홈 리포트, 리포트 목록, 분류·검색 결과는 같은 리포트 순서를 유지합니다. 공지사항의 상단 고정·게시일 정렬에는 영향을 주지 않습니다. 기존 숫자 `표시 순서`는 사용하지 않습니다.

## 과거 자료를 넣을 때

먼저 원래 발표 학기를 확인하고, 학기마다 10 간격으로 순번을 정해 일괄 입력합니다. 업로드한 날짜를 학기로 대신 쓰지 않습니다. 현재 테스트 리포트에 적용한 학기·순번은 초기 관리 예시이며, 실제 발표 학기가 다르면 값을 수정하면 됩니다. 기존 400개 자료의 일괄 이관은 별도 작업입니다.

## 기술적 동작

두 속성은 기존 목록 조회 응답에서 함께 읽습니다. 추가 Notion 요청이나 DB 쓰기 권한은 필요하지 않습니다. 서버의 목록 캐시·동시 요청 합치기·페이지 이동을 유지하며, 정렬 후 검색·분류·페이지 이동을 적용합니다. 공개 체크·게시일·DB 소속 검증도 유지합니다.
