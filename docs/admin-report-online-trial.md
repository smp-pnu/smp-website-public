# 관리자 실자료 → 별도 온라인 게시 시험

2026-10-27, `feature/admin-report-live-trial-20261027`에서 수행했다. 시험 주소는 https://smp-report-publication-trial.smp-website.workers.dev/research 이다. **일회 게시 스냅샷**이며 지금 관리자에서 새로 승인해도 이 사이트가 자동 갱신되는 것은 아니다.

## 대상과 격리

- 관리자에 실제 저장된 인바디 PDF 한 건, 27쪽을 사용했다. 이 원본은 초기 시험판의 D1 저장 파일이다. 이번 실자료 시험이 실제 Drive 원본의 게시 경로까지 검증한 것으로 해석하지 않는다. Drive 경로는 별도 native workerd + 모의 Drive 검증을 통과했다.
- 관리자 화면에서 제목 쉼표 앞 공백만 정리했다. 초안 revision 4 저장 중에는 이전 승인 revision 3이 유지됐고, 원문을 확인한 뒤 revision 5를 승인했다. PDF와 투자 수치는 바꾸지 않았다.
- 별도 Worker·D1·정적 자산만 생성했다. 배포 스크립트는 관리자 DB·운영 DB·이전 시험 DB를 거부하고, 전용 대상 이름과 계정·호스트·DB 표식을 확인한다.
- 이 Worker에는 Notion·Drive·AI·운영 Worker의 자격증명, 서비스 바인딩, 예약 작업이 없다. 리포트 조회 경로만 허용한다. 홈페이지의 다른 메뉴는 이 시험 범위가 아니다.
- 관리자 UI의 ‘시험 승인’ 의미를 바꾸지 않았다. 원본 전달을 위해 관리자 시험 Worker에 승인본 읽기 API만 반영했다. 해당 API는 지정 ID·짧은 만료·전용 키를 모두 요구한다.
- 자료 준비 후 원격 내보내기 키와 범위 설정을 모두 삭제하고 이전 키 요청이 404인지 확인했다. 로컬 임시 키 파일도 제거했다.
- 기존 Notion 운영과 `pnusmp.com`의 배포·연결을 변경하지 않았다. 운영 리포트 목록 191건은 시험 전후 응답 바이트가 일치했다.

## 준비·열람

PDF 원문을 한 번 검증한 뒤 표지, 첫 3쪽 미리보기, 전체 27쪽 이미지 묶음, 원문 다운로드 청크를 만든다. 원본은 28,934,152바이트, 전체 페이지 묶음은 약 10.3MiB다. 같은 PDF의 새 승인본을 준비할 때 재다운로드·재변환 없이 기존 자산을 재사용했다.

방문자는 정적 파일과 전용 게시 메타데이터만 읽는다. PDF 변환·LLM 추론·Notion/Drive 요청은 방문 중 실행하지 않는다. 이 시험의 최초 준비·게시 명령은 로컬에서 한 번 실행했지만, 배포된 페이지 열람은 Mac이 꺼져 있어도 동작한다. 상시 게시 작업은 별도 구현 대상이다.

실제 배포 검증 중 로컬 테스트에서 드러나지 않던 두 차이를 보완했다. Cloudflare Fetcher 객체를 그대로 전달해야 원본 청크를 읽을 수 있으며, 확장자를 모르는 정적 페이지 묶음에는 검증된 메타데이터를 바탕으로 바이너리 형식·길이 헤더를 명시해야 한다. 재발 방지 테스트에 두 경우를 포함했다.

최종 온라인 검증: 승인된 한 건만 목록·검색·상세에 표시되고, 다운로드한 원문은 저장 원본과 SHA-256이 일치한다. 전체 묶음 27쪽을 해석했으며 브라우저에서 `prepared` 경로 사용, 12·27쪽 이동, 150% 확대, 검색 조건을 유지한 목록 복귀를 확인했다. 무승인 경로·오래된 해시·직접 원본 주소는 차단되고 수정 요청은 405다. 실제 확인 시 브라우저 오류 로그는 없었다.

## 한도와 종료

- 공개 시험 경로 호출: 하루 최대 500회, 별도 분당 제한. 한도 도달 시 429를 반환한다. **방문자 수나 다운로드 개수 500회를 뜻하지 않는다.**
- 마지막 빌드로부터 7일 후 조회 경로가 410으로 종료된다. 이번 만료는 2026-11-03 14:58 KST다. Worker·DB 자동 삭제는 하지 않는다. 검색엔진 수집은 robots와 응답 헤더로 차단한다.
- 방문자 자동 변환·AI 사용 없음. 정적 파일당 25MiB 미만, 파일 총량 256MiB·2,000개 이하, Worker gzip 2.5MiB 이하로 빌드 자체를 제한한다.
- 이번 준비 자산은 약 39MiB, UI 포함 배포 정적 파일은 약 94MiB다. 원문 바이트를 새 게시 D1에 넣지 않는다.
- 유료 플랜, 카드 등록, R2 등 새 과금 서비스를 연결하지 않았다. Cloudflare 무료 할당량은 기존 서비스와 계정 단위로 공유되므로 이 시험 상한이 계정 전체 한도를 보장하지는 않는다.

## 실행·증거

`scripts/report-publication-trial.mjs`의 `prepare → build → dry-run → deploy`를 명시적으로 실행한다. 저장소 밖의 전용 비공개 출력 폴더와 무시된 대상 설정을 사용하며 `.env`를 자동 로드하지 않는다. 같은 출력 폴더는 동일 대상만 재개할 수 있고, 원격 DB에 다른 게시 스냅샷이 이미 있으면 교체를 거부한다. `find_additional_modules: false`로 원문 파일이 Worker 코드 모듈에 묶이지 않도록 했다.

로컬 증거 폴더 `SMP-admin-live-publication-20261027/`에는 승인 전후 메타데이터, 준비·재사용 결과, 배포 로그, API 검증, 키 폐기 확인, 브라우저 화면을 보관한다. 원본 PDF·승인 스냅샷·DB 파일·키 파일을 Git에 추가하지 않는다.

이후 필요한 것은 소수 실제 Drive 리포트 시험, 관리자 게시 성공/실패 상태 표시, 원격 게시 작업의 재시도·롤백, 기존 주소/소유권 보존 이관이다. 이 검증과 사용자 확인을 마치기 전에는 운영 관리 주체를 전환하지 않는다.
