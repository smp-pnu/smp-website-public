# 회원 명단 관리

학회 Notion의 `SMP 웹사이트 관리 → SMP 명단 관리 → SMP 회원 명단`에서 관리합니다. 한 사람당 한 행이며, 공개된 명단이 MEMBERS / ALUMNI와 통합 검색에 함께 반영됩니다. 관리 페이지를 인터넷에 게시할 필요는 없습니다.

| 속성 | 형식 | 입력 방법 |
| --- | --- | --- |
| 이름 | 제목 | 필수 |
| 기수 | 숫자 | 필수. `41`처럼 양의 정수 입력 |
| 구분 | 선택 | `MEMBERS` 또는 `ALUMNI` |
| 공개 | 체크박스 | 확인한 명단만 체크. 새 행은 기본 비공개 |
| 학과 | 텍스트 | 선택 |
| 학번 | 텍스트 | 선택. `26학번`처럼 표시할 문구 입력 |
| 사진 | 파일과 미디어 | 선택. 가벼운 JPG·PNG·WebP 업로드 |
| 사진 링크 | URL | 선택. 사진 파일이 없을 때 쓸 HTTPS 이미지 주소 |
| 표시 순서 | 숫자 | 선택. 같은 기수 안에서 작은 값부터 표시 |

## 매 학기 사용하는 방법

1. `새로 만들기`로 회원을 추가하고 이름·기수·구분을 입력합니다. 기수별 묶음 안의 `새 페이지`로 추가했다면 기수가 맞는지 확인합니다.
2. 학과·학번·사진을 입력하고, 공개할 내용인지 확인한 뒤 `공개`를 체크합니다.
3. 홈페이지를 새로고침하여 확인합니다. 변경 알림과 캐시 갱신에 따라 보통 1~2분 정도 걸릴 수 있습니다. 이미 열린 화면은 자동 갱신되지 않습니다.
4. 새 기수에 공개된 회원이 생기면 홈페이지 기수 선택 목록이 자동으로 늘어납니다. 숫자를 코드에 추가하거나 사이트를 재배포할 필요가 없습니다.
5. 한 기수를 ALUMNI로 이동하려면 노션에서 그 기수로 필터한 뒤 해당 행들을 선택하여 `구분`을 일괄 변경합니다. 나머지 기수의 구분은 유지됩니다.

노션의 `기수별 명단`은 기수를 큰 수부터 묶고, 각 묶음 안에서는 표시 순서로 정렬합니다. 홈페이지도 최신 기수를 먼저 보여줍니다. 순서는 `10, 20, 30`처럼 입력하면 사이에 `15`를 추가하기 편합니다. 비어 있거나 0 이하인 순서는 뒤로 가며, 순서가 같은 경우 이름순으로 표시됩니다. 드래그 순서는 홈페이지에 반영하지 않습니다.

`공개`를 해제하거나 행을 휴지통으로 옮기면 명단과 검색에서 빠집니다. 사진만 없애려면 `사진`과 `사진 링크`를 모두 비웁니다. 원본 사진의 외부 공유 권한은 별개입니다.

## 개발·운영

- 서버 환경변수 `NOTION_MEMBERS_DATA_SOURCE_ID`에 **데이터 소스 ID**를 등록합니다. DB ID와 다릅니다. 기존 읽기 전용 Notion 연결이 관리 페이지의 하위 명단 DB를 읽을 수 있어야 합니다.
- `lib/member-model.ts`: 공개 검사, 필요한 필드만 선택, 정렬, 기수 목록, 검색 항목.
- `lib/member-catalog.ts`: 페이지 나눔 조회, 동시 요청 병합, 서버 캐시.
- `components/members-directory.tsx`: 전달받은 공개 명단을 기수별로 표시. 기수 선택은 브라우저에서 처리하므로 Notion을 다시 호출하지 않습니다.
- 명단은 100명씩 조회하며, 동시에 들어온 요청은 하나의 조회를 공유합니다. 서버 캐시는 60초이고 기존 서명된 Notion 변경 알림에서도 갱신합니다. 오류 중 120초 이상 지난 명단은 계속 노출하지 않습니다. 비공개 메모 등 미지정 속성은 응답에 포함하지 않습니다.
- 사진은 원본을 지연 로딩합니다. 사진 처리용 Blob 저장·변환 작업을 추가하지 않습니다.
- Notion 연결이 실패해도 삭제된 회원을 예전 코드 명단에서 되살리는 대체 처리는 하지 않습니다. 오류 안내를 표시합니다.
- 이름이 같은 사람이 있을 수 있으므로 이름 기준으로 합치지 않고 노션 페이지 ID로 식별합니다.

초기 이전 시 기존 공개 명단 628명의 이름·기수·학과를 대조했습니다. 기존 자료가 없는 기수는 표시하지 않으며 새 공개 회원을 등록하면 자동으로 나타납니다. 관리 페이지 주소와 실제 ID는 비공개 인수인계 자료 및 서버 환경변수에 둡니다.
