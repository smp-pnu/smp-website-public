# 리포트 탐색과 노션 관리

## 관리자가 입력할 항목

기존 `제목`, `공개`, `게시일`, `분류`, `작성자`, `요약`, `외부 링크`, `학기`, `학기 내 순서`를 그대로 사용합니다. 기존 제목이나 PDF를 다시 등록할 필요가 없습니다.

웹사이트 필터는 **기간 · 산업 · 분류** 세 가지입니다. 각각 노션의 `학기`, `업종`, `분류` 속성에 대응합니다. 기업분석·산업분석·신입세션·부증련·개인스터디·UIC 등은 모두 `분류`에서 관리하며, 카드의 분류 표시와 필터가 같은 값을 사용합니다.

추가 속성은 모두 선택 사항입니다.

| 노션 속성 | 유형 | 웹사이트 반영 |
| --- | --- | --- |
| 업종 | 선택 | 기존 분류 옆 작은 산업명, 산업 필터, 관련 리포트 |
| 기업명 | 텍스트 | 기업 검색 및 상세 표시. 비워 두면 기업분석 제목의 `[기업명]`을 활용 |
| 종목코드 | 텍스트 | 종목코드 검색 및 상세 표시. `041830`처럼 앞자리 0을 유지 |
| 보고서 종류 | 선택 | 보조 메타데이터와 검색어. 분류 필터 관리에는 입력할 필요 없음 |
| 활동 | 선택 | 보조 메타데이터와 검색어. 분류 필터 관리에는 입력할 필요 없음 |
| 투자 포인트 | 텍스트 | 줄바꿈으로 최대 3개 입력. 상세의 접을 수 있는 투자 포인트 영역 |

`분류`의 기존 이름과 색상은 카드에 그대로 표시됩니다. 산업은 FnGuide의 [WICS 분류](https://www.wiseindex.com/About/WICS)를 사용합니다. `업종`에는 소분류, `섹터`에는 공식 대분류가 자동 계산됩니다. 산업 전체를 다룬 자료는 여러 업종에 걸칠 때 대분류만 지정할 수 있습니다. 사이트의 산업 메뉴는 최대 10개 대분류 중 자료가 있는 항목만 표시하며, 해당하는 세부 업종을 자동으로 함께 검색합니다. 카드는 세부 업종 하나만 표시합니다. 기존 세부 업종 필터 링크도 계속 사용할 수 있습니다.

노션 선택값에는 쉼표를 쓸 수 없어 `호텔·레스토랑·레저`처럼 중간점을 사용합니다. 웹에서는 공식 WICS 이름으로 정규화합니다. 상장폐지·비상장 등 현재 WICS 조회가 없는 과거 자료는 보고서 사업 내용을 사람이 확인해 분류하고 `검토 메모`에 그 근거를 남깁니다. 공식 최신 조회 결과와 수동 대응 분류를 구별합니다.

## 새 리포트 기업정보 자동 입력

1. 기존처럼 제목과 PDF의 `외부 링크` 또는 `첨부파일`을 입력합니다. 제목을 `[기업명] 소개 문구`로 적으면 가장 안정적으로 식별합니다.
2. Notion 웹훅이 저장을 감지하면 **빈 기업명·종목코드·업종만** 채웁니다. 등록된 기업은 검증된 기업명/옛 사명으로 코드를 찾고, 신규 기업은 PDF 첫 2페이지의 기업명·종목코드를 공식 기업정보와 대조합니다. 기존 수동 입력은 덮어쓰지 않습니다.
3. `기업정보 상태`가 **자동 입력**이면 완료입니다. **확인 필요**이면 `검토 메모`를 보고 기업명 또는 6자리 종목코드를 입력합니다. 입력값이 바뀌면 다시 시도합니다. 이미지 PDF, 복수 기업, 해외·비상장 종목, 모순된 코드 등은 추측하지 않습니다.
4. `분류` 또는 `보고서 종류`가 산업분석이면 단일 기업정보를 자동 입력하지 않습니다. 업종은 관리자가 지정합니다. 직접 수정한 업종에 맞춰 섹터도 바뀝니다.

기업명은 현재 이름을 사용하고 보고서 제목에는 당시 이름을 유지합니다. 합병·분할로 법인과 코드가 달라진 경우, 과거 보고서의 종목을 신설 회사 코드로 바꾸지 않습니다. 제목에 남은 옛 이름과 현재 기업명·종목코드 모두 검색됩니다.

자동 입력은 저장 시에만 실행합니다. 일반 방문, 검색, 필터 조작은 기업정보 사이트나 PDF 추출을 호출하지 않습니다. 입력값과 PDF 식별자로 만든 `기업정보 동기화키`는 중복 알림 및 자동 입력 후 다시 오는 알림을 건너뛰는 내부 값이므로 관리자 표에서 숨겨도 됩니다. 내용을 재확인하려면 이 값만 비우거나 필요한 입력을 수정합니다. 파일을 같은 Drive ID로 덮어쓴 경우에도 키를 비워 재실행할 수 있습니다.

자동 입력은 무료 텍스트 추출을 사용하며 별도 AI/OCR 유료 서비스가 없습니다. PDF는 최대 32MB, 첫 2페이지만 추출합니다. 이미지 PDF 또는 초과 파일은 기업명/코드를 직접 입력하면 됩니다. 외부 조회가 일시 실패하면 웹훅 재시도 대상으로 남기며 추정값을 저장하지 않습니다.

설정에는 `NOTION_METADATA_WRITE_ENABLED=true`, Notion의 **콘텐츠 업데이트** 기능, `기업정보 상태`(선택), `기업정보 동기화키`(텍스트), `섹터`(수식)가 필요합니다. 새 페이지 생성·댓글·사용자 정보 권한은 필요하지 않습니다. 연결의 업데이트 권한은 해당 연결에 공유된 다른 CMS 페이지에도 적용되지만, 서버는 리포트 DB 소속을 쓰기 직전에 다시 확인하고 기업정보 관련 필드만 갱신합니다. 자동화를 끄려면 환경변수를 false로 바꾸고 재배포합니다.

요약은 `타겟년도: 2027년 · Target price: 79,500원 · 상승여력: 48.1%` 형식을 유지합니다. 목표주가가 없는 보고서는 `Not Rated`를 입력합니다. 상세 화면은 이 원문 값으로 타겟년도·목표주가·상승여력을 표시하며 숫자를 추정하지 않습니다. 일반 소개문 형식의 요약은 원문 그대로 보여줍니다.

## 방문자 사용 흐름

- 기간(학기)·산업·분류를 선택하면 바로 필터가 적용됩니다. 세 조건을 함께 사용할 수 있으며 선택한 조건을 개별 해제하거나 초기화할 수 있습니다.
- 기존 종류·활동 조건이 담긴 링크도 열 수 있습니다. 새 분류를 선택하면 이전 종류·활동 조건을 대체합니다.
- 검색 미리보기와 전체 검색결과는 동일한 필터와 검색 규칙을 사용합니다. 기업명·종목코드도 검색됩니다.
- 그리드/목록 보기, 검색어, 필터, 페이지는 URL에 저장됩니다. 상세에서 목록으로 돌아가면 기존 조건과 리포트 위치로 복원됩니다.
- 상세 링크 복사는 개인 검색 조건을 제외한 해당 리포트의 주소를 복사합니다.
- PDF는 한 번에 한 페이지를 표시합니다. 지원 브라우저에서는 전체 화면을 사용할 수 있습니다. 페이지 이동 시 이 브라우저에 마지막 페이지를 저장하고, 다시 열면 이어 읽기를 제안합니다. 저장이 막힌 브라우저에서도 열람할 수 있습니다.
- 관련 리포트는 같은 기업 → 같은 업종 → 같은 학기 중 첫 번째로 결과가 있는 그룹에서 최대 3건을 기존 목록 순서로 표시합니다.

## 운영과 비용

목록과 필터는 기존 공개 목록 캐시를 공유합니다. 검색어 입력은 브라우저에서 처리하므로 타이핑할 때 노션 API를 호출하지 않습니다. 관련 리포트 역시 같은 목록 캐시를 사용하며 개별 후보 페이지를 다시 조회하지 않습니다. 상세·PDF·첨부파일의 공개 여부 확인은 기존 방식으로 유지합니다.

메타데이터 수정도 노션의 최종 수정 시각을 바꾸므로 기존 표지 동기화 대상이 될 수 있습니다. 전체 자료를 매번 일괄 수정하지 말고 새 리포트 등록 또는 필요한 분류 보완 시 입력하세요.

정렬은 [리포트 순서 안내](report-order.md)를 따릅니다. `학기` 내림차순 → `학기 내 순서` 오름차순이며, 노션 화면의 행 드래그만으로 사이트 순서가 바뀌지는 않습니다.
