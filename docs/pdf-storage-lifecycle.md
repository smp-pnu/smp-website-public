# PDF 원본 교체와 보관

관리자 리포트 목록의 **PDF 교체**는 새 원본을 별도 저장하고 내용을 검토한 다음 기존 게시글의 초안에 연결합니다. 제목·분류·순서·게시글 주소는 유지됩니다. 새 표지와 열람 파일을 준비하고 게시 승인이 완료될 때까지 기존 공개본을 유지합니다. 업로드 완료 재시도는 같은 원본을 중복 생성하지 않습니다.

이전 PDF는 현재 초안·승인본·게시 준비 작업·최근 수정 이력에서 사용하는 동안 보관합니다. CMS는 최근 승인 이력 5개를 유지합니다. 해당 참조가 모두 사라진 관리자 업로드는 자동 정리 대상으로 등록하고, 30일간 복원 가능한 상태로 보관한 뒤 Drive 휴지통으로 옮깁니다. Drive 휴지통은 자동으로 비우지 않으므로 휴지통에 있는 파일도 Google 계정 용량에 포함됩니다.

정리는 관리자 화면을 열었을 때 최대 시간당 한 번, 회당 최대 2개씩 실행합니다. 방문자의 페이지 조회로 Drive 목록을 순회하거나 PDF를 검사하지 않습니다. Drive 오류가 발생하면 원본과 확인 정보를 보존하고 다음 시점에 재시도합니다. 파일 소유권·관리 폴더·앱 표시·원본 체크섬이 일치하지 않으면 자동 삭제를 중단합니다.

기존 Notion에서 연결한 Drive 파일은 관리자 앱이 생성한 파일이 아니므로 자동 삭제하지 않습니다. 제한된 Drive 권한을 유지하기 위한 구분입니다. 사용 여부를 확인한 뒤 학회 Drive에서 직접 정리해야 합니다.

바이트가 완전히 동일한 파일은 검증된 원본 연결표로 중복 저장을 줄일 수 있습니다. 수정 이력 자체는 변경하지 않습니다. 파일명이나 AI 판단만으로 동일 파일로 취급하거나 삭제하지 않습니다.

검증: `pnpm test`는 승인본·이력·게시 작업·공개 원본 보호를 확인합니다. `pnpm test:admin:drive`는 격리된 로컬 Cloudflare 실행 환경과 가상 Drive로 업로드 실패/재시도, 초안 교체, 승인 후 공개 전환, 이력 보존, 정리 유예, Drive 휴지통 실패/재시도, 새 원본 무결성을 확인합니다. 실제 계정·파일·유료 서비스를 사용하지 않습니다.
