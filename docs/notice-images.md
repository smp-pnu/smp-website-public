# 공지 사진 관리

공지 글과 사진은 Notion 공지 DB에서 함께 편집합니다. 사진은 본문에 **직접 업로드**하고 캡션을 적습니다. 카페 사진 주소나 Drive의 보기 링크를 이미지 URL로 붙이지 않습니다.

공개·게시일을 설정하면 GitHub 게시 작업이 사진을 읽고 WebP로 변환하여 Cloudflare의 웹사이트 정적 파일로 배포합니다. 본문에는 이 사이트의 이미지 주소를 저장합니다. 사진 열람 때마다 Notion이나 Drive를 호출하거나 변환하지 않습니다. 본문·사진 반영은 약 15분 간격이며 GitHub 예약 실행은 지연될 수 있습니다.

Drive는 큰 원본 사진·PDF·행사 자료의 보관에 사용합니다. 필요하면 `공지사항 / 연도 / YYYY-MM-DD_행사명 / 원본사진·첨부파일`로 직접 정리하고, 웹에서 보여줄 사진만 Notion에 업로드합니다. **Notion 사진의 Drive 자동 백업은 현재 운영 경로에 구현되어 있지 않습니다.** Drive 보기 링크는 본문 사진용 직접 주소가 아니며, 기존 PDF 첨부 방식과 구분합니다.

현재 이미지 처리기는 PNG·JPEG·WebP·GIF, 파일당 최대 10 MiB·4천만 픽셀을 허용하며 최대 2048×4096 범위로 축소합니다. Notion 플랜의 업로드 제한이 더 작으면 그 제한이 먼저 적용됩니다. GIF는 정지 이미지로 게시됩니다. 동일한 변환 결과는 같은 해시 주소를 사용합니다.

사진이 안 나오면 Notion에서 원본이 보이는지와 마지막 게시 작업을 확인합니다. Notion 업로드 링크는 만료되므로 그 주소를 홈페이지에 고정하지 않습니다. 인식하지 못하는 Notion 업로드 주소는 게시를 보류하고 기존 본문을 보존합니다. 공식 파일 호스트를 확인한 뒤 허용 목록을 수정하며, 임의 S3 주소 전체를 허용하지 않습니다.

공개 해제는 글 접근을 막지만 이미 배포한 이미지 URL이나 다운로드된 복사본을 회수하는 기능은 아닙니다. 공개할 수 있는 사진만 사용합니다.
