# SMP | 부산대학교 금융투자학회

부산대학교 금융투자학회 SMP의 공식 웹사이트 소스 코드입니다.

**웹사이트: [pnusmp.com](https://pnusmp.com)**

## 주요 기능

- 학회 소개, 활동 및 성과 안내
- 기업·산업 분석 리포트 검색과 필터
- 리포트 PDF 열람 및 다운로드
- 공지사항, 모집 안내 및 기수별 회원 명단

## 콘텐츠 관리

공지·리포트·회원 명단은 Notion에서 관리하고, PDF 원본은 Google Drive에 보관합니다. 웹사이트는 Cloudflare에서 운영합니다.
